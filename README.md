An unofficial CSL style implementing the 5th edition of OSCOLA (Oxford
University Standard for Citation of Legal Authorities, published March
2026) for use in Zotero.

Oxford's own official Zotero/EndNote/LaTeX/RefWorks styles still relate
to the 4th edition as of this writing. This style was built to close
that gap, with particular attention to:

- EU legislation (regulations, directives, decisions, treaties)
- CJEU / General Court case citations (ECLI format)
- International sources: ICJ, ICC, ECtHR, arbitral tribunals, treaties
- Academic secondary sources (books, articles, theses, reports, websites)

## Installation

1. Download `oscola-5th-edition.csl` from this repo.
2. Open Zotero → Settings → Cite → Styles tab.
3. Click "+" at the bottom of the style list and select the file.
4. In Word/LibreOffice, open the Zotero plugin's Document Preferences
   and select "OSCOLA 5th edition (EU, international and academic
   sources)" from the list.

## Metadata entry guide

See `oscola-5-zotero-metadata-guide.md` in this repo for field-by-field
instructions on entering EU legislation, treaties, cases, and secondary
sources correctly in Zotero.

## Known limitations

- Tables of Cases / Tables of Legislation aren't auto-generated — split
  legal sources into separate tables manually if your thesis requires them.
- Fill in the Short Title field for cases so subsequent footnotes use
  the short form.
